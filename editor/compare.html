No subscription. No account. No dead codes.

Questions

Do PermaPath QR codes expire?

No. Each code points to a permanent page on Arweave, a network designed to store data indefinitely. There’s no subscription to lapse and no account to close.

Is PermaPath really free?

Yes. Links are small records stored on Arweave, and uploads that small are free, so there’s nothing to charge for.

What happens if PermaPath shuts down?

Printed codes keep working, because they point to Arweave, not to permapath.link. The app itself is stored on Arweave too, so you can still change your links.

Can I change where a QR code goes after printing it?

Yes. Sign in with your key and point the link somewhere new. The printed code stays exactly the same.

Can I password protect a link?

Yes. Turn on Password protect and people need the password to see where the link goes or what the page says.

Do I need an account?

No. You create a key, a long password, and save it in your password manager. Lose it and nobody can recover it, so keep it safe.

Is PermaPath open source?

Yes, under the MIT license. The code is on GitHub, so anyone can check how links, keys and password protection work, or run their own copy.

When is a subscription service the better choice?

If you need detailed scan analytics, or changes that are guaranteed to be instant, a subscription service does those well. PermaPath is for codes that must keep working for years.

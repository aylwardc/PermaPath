How it works

  1. Create a key and save it in your password manager. It’s your account: no email or sign-up.
  2. Create a link to any web address, or write a simple page with text and a photo, no website needed. Add a password if it’s private. Download its QR code to print.
  3. Change the destination whenever you need to. Scans follow within seconds.
Tip: ask AI to do it for you. This site is optimized for AI agents, and ask for what you want.

Not a good fit for

  • Highly sensitive secrets. Password protection uses strong encryption, but old versions are never deleted and a short password could eventually be guessed. No state secrets, social security numbers, or DNA results please.
  • Marketing analytics. PermaPath counts scans and nothing more: no locations, no devices, nothing about who scanned.
  • Changes that must be instant. Most go live within seconds, but some take up to 20 minutes.
  • Big files or full websites. You can link to anything that’s already online, but new uploads can get expensive, we’re trying to keep this free.

Good to know

  • Don’t lose your key. It’s the only way to make changes. If you do lose it, your codes keep working but can’t be altered. Nobody can recover it for you, so save it in your password manager and print the recovery phrase.
  • Add a password to private links. With Password protect on, people need the password to see where a link goes or what a page says.
  • Changes usually go live within seconds, occasionally up to 20 minutes.
  • Each code points to a permanent page on Arweave, a network designed to store data indefinitely. Your printed codes keep working even if this site goes away.

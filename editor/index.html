Stop reprinting

Printed things outlive the links on them. Menus change, documents get new versions, websites move. With PermaPath you update where a code goes instead of replacing what’s printed, from your phone, in seconds.

How it works

  1. Create a key and save it in your password manager. It’s your account: no email or sign-up.
  2. Create a link to any web address, or write a simple page with text and a photo, no website needed. Add a password if it’s private. Download its QR code to print.
  3. Change the destination whenever you need to. Scans follow within seconds.
Tip: let an AI assistant do it. Tell ChatGPT, Claude or another assistant: “Read permapath.link/llms.txt and make PermaPath links for…” It can draft a list for you to import, or, if it can run commands and you give it a key, make the links itself. Use a separate key for that. Instructions for AI assistants

Not a good fit for

  • Highly sensitive secrets. Password protection uses strong encryption, but old versions are never deleted and a short password could eventually be guessed. Use a long one for anything important.
  • Marketing analytics. PermaPath counts scans per day and nothing more: no locations, no devices, nothing about who scanned. Counts are public.
  • Changes that must be instant. Most go live within seconds, but some take up to 20 minutes.
  • Big files or full websites. Pages you write here are simple: text and one photo.

Built to outlast this website

Each code points to a permanent page on Arweave, a network designed to store data indefinitely. Your printed codes keep working even if this site goes away.

Good to know

  • Your key is the only way to make changes. If you lose it, your codes keep working but can’t be pointed anywhere new. Nobody can recover it for you, so also keep its recovery phrase (24 words) on paper.
  • Lock what’s private. With Password protect on, people need the password to see where a link goes or what a page says. Without it, a link works like a printed sign: anyone can see where it points. Link names always stay visible.
  • Changes usually go live within seconds, occasionally up to 20 minutes.
  • More options on each link: count scans, turn it off on a date with a message, or send iPhones, Android phones or certain days and times somewhere else.
